# Philosophy

KAT is a semantic software repository designed around the idea that software is not merely source code, but an evolving system of knowledge, decisions, structures, behaviors, and artifacts.

KAT captures and maintains the knowledge that defines the intended state of the software. This specification is represented through an authoritative semantic model, allowing the software to remain traceable, explainable, validatable, and able to evolve over time.

Source code, documentation, tests, configurations, and other artifacts represent, implement, validate, or materialize this knowledge. They are part of the software system, but they do not independently define its intended state.
