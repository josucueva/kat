# Non-goals

KAT is not intended to:

* Replace Git as a version control system
* Provide version control for arbitrary graph structures
* Serve as a general-purpose graph modeling or visualization tool
* Be an AI-first software development tool
* Passively extract and document existing systems
* Replace software architecture practices or human decision-making

These are project-level non-goals: they describe what KAT fundamentally does not want to become. They are distinct from release-scope limitations, which exclude capabilities from specific versions and are listed in `requirements.md` (Scope Limitations). For example, branching may conceivably appear in a later release without making KAT a Git replacement.
